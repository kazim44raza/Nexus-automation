# Azorvin — AI Systems & Automation

This repository contains the official website for [Azorvin](https://www.azorvin.com/), an AI systems and business automation company for service businesses.

Azorvin designs practical systems for:

- AI chatbots and customer messaging
- AI voice agents and call handling
- WhatsApp automation
- Appointment booking and reminders
- Lead qualification and CRM updates
- Business workflow automation

The systems are designed with explicit human handoffs for exceptions, sensitive decisions, and requests that need judgment.

## Technology

Next.js, TypeScript, Tailwind CSS, Prisma/PostgreSQL, NextAuth, and server-side AI integrations.

Secrets and production configuration are never committed. Use `.env.example` as the configuration reference and keep real values in ignored environment files or the deployment platform.
